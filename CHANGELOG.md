# Changelog

## 0.4.0 (в работе)

- The mod is called **Barrens Voice** now (after the Barrens chat): the addon's folder is `BarrensVoice`, its command `/bv`, its saved settings `BarrensVoiceDB`; the companion starts with `BarrensVoice.cmd`, its Python package is `bv`, its logs `bv-YYYY-MM-DD.log`. Nothing carries over from the old names by itself.
- **Updates by themselves** (installed with the installer): the launcher checks GitHub Releases at start and hourly, downloads the new version, checks it against the signed manifest, builds it beside the current one and switches to it when the game and the voice-over are not running; a version whose companion fails right at start twice is rolled back. Settings: «Обновлять автоматически» (on) and «Получать тестовые версии» (pre-releases). The app's version is pyproject.toml's now, the addon's its own.
- **A launcher window** instead of the companion's console (`BarrensVoice.pyw`; `BarrensVoice.cmd` prepares Python and opens it): the state (companion, game, race voices with the video card, the link with the addon), the companion's log, the start options (launch the game with Barrens Voice, close with the game, start at Windows sign-in — then it waits in the tray and starts the companion when the game starts), the installed games with the addon's version in each and a button to install or update it, Play, settings, help, and a notice when a newer version is on GitHub Releases. The cross closes it with the companion (asking if the game runs); it hides in the tray by itself when it starts the game and at Windows sign-in; when the launcher ends, the companion ends too. The games are found where they last ran, from the registry and Battle.net's settings, and in the usual folders on every local disk. It follows the Windows screen scale. The retail game is chosen in the window: `BarrensVoice-Retail.cmd` is gone; `BarrensVoice.pyw` and `BarrensVoice.cmd` take the same switches (`--retail`, `--console`, `--f5`…, `--help`). Its icon is the addon's, `bv/launcher/icon.ico`.
- Log levels: every line of the companion's log carries one (DEBUG, CHAT, INFO, WARN, ERROR; `bv/logs.py` decides by the message). The launcher's main window shows only how things go (INFO and up, without the level); «Журнал» opens the full log live, with filters by level, search, copying (also «для отчёта»: the version, Windows, the ONNX Runtime build, the video cards, the race voices' state, the games with their addon and the settings changed from the defaults — folders, the WoW account and players' names left out, the home folder as `~` — then the last 300 lines of every level) and scrolling that follows new lines only while at the bottom.
- A line whose speech runs to the very end of its length (about one in eight) is made again with more length, as before; the launcher's settings can instead have Whisper listen to its ending first and make it again only when the last word is not heard (`f5_end_check`: "silence" by default, "whisper" — a second saved on such lines for about 1.5 GB of video memory).
- The model cache's warning about symlinks on Windows (it keeps plain copies without developer mode, which costs nothing here) and two of RUAccent's own notices (a regex string without r"", an argument huggingface_hub ignores) are no longer shown while the models download.
- `BarrensVoice.cmd` downloads the models while installing (`python -m bv --fetch-models`: F5 in ONNX, Whisper, RUAccent, ~3 GB), so the first start does not wait for them; what fails to download, the first start downloads.
- The ONNX models of F5 are downloaded from Hugging Face (`rgeraskin/barrens-voice-f5-onnx`) at the first start, unless they are already in `models\f5-onnx` or `f5_onnx_dir`.
- The game no longer stutters while chat is read. On NVIDIA the race voices run through ONNX Runtime with CUDA (`onnxruntime-gpu`): DirectML held the video card for each whole denoising step (~100 ms), and the game's frames waited — about one hitch per step; with CUDA, as with torch before, none. `BarrensVoice.cmd` installs the CUDA build when it finds an NVIDIA driver and the DirectML build otherwise; the companion takes CUDA, then DirectML. Also: every ONNX session gets two threads that sleep when idle (the last step, Vocos, ran on all cores with spinning threads), and the companion runs below normal priority (`share_with_game`, `onnx_threads`). RUAccent's `koziev` model is kept in the model cache too, so a new environment starts offline. Whisper, which builds the voice bank, runs on CUDA too (it took the video card only with DirectML and ran on the processor otherwise).
- Updates: a failed preparation is tried again at the next check (it stopped all further updates), and «Что нового» of a test build opens its own release page.
- Updates keep uv current too: the signed manifest names the release's uv (version, its GitHub build, SHA-256), and an install with another one fetches it, checks it, builds with it and puts it in place.
- The install folder has «Barrens Voice.exe» with the app's icon: a small starter of the current version, which a player finds there if the shortcut is gone; the shortcuts and the sign-in start go through it.
- The launcher says in its log at once when the chosen game has no addon (not only when the voice-over would start).
- The launcher's settings have a folder field for each game, «Папка WoW Forever» and «Папка WoW Retail» (the two may be on different disks), shown as found when not set; the World of Warcraft folder above a game is taken for the game's own. They are game_dirs in config.json; the single wow_dir is still read.
- «Запускать игру вместе с Barrens Voice» is off by default: opening Barrens Voice does not start the game unless asked («Играть», or the check).
- The launcher opened by hand starts the companion only with the game: when it runs, when «Запускать игру» is on, on «Играть», or when the game appears - not at once without it, so the race voices take video memory only for a game. (At Windows sign-in it already waited in the tray.)
- «Играть» with Battle.net not running: Battle.net drops the launch command while it starts and logs in, so the game did not start. The command is sent once more when its window is up (or after a minute) - only once, a second one may start a second game.
- The launcher's main window has hints: its three start checks (what «Запускать игру», «Закрываться вместе с игрой» and «Запускать при входе в Windows» do, and when the race voices take video memory) and «установить аддон» / «обновить аддон».
- The log window: «Копировать» copies the selection, or every line the filters show without one; its buttons have tooltips, «Копировать для отчёта» telling what goes into the report.
- The speaker's name and the line had no space between them («Вася пишет:привет» in the log and to the synthesis, an emote said «Васясмеётся»): `text.plain` stripped the line's leading space; `protocol.with_name` joins them with one.
- The launcher's main window: its log lines are written to fit one line (details in the full log, indented), a line that still does not fit is wrapped under its time instead of cut; the version shows a test build as «0.4.0 beta 5»; the settings point to the description of config.json by a link to this version's docs/config.md.
- Test builds carry their own version (tag v0.4.0-beta.5 -> 0.4.0b5): the updater takes a newer beta, and the release over its betas.
- The launcher's main window speaks plainly: the race voices load without «(F5-TTS)», the link with the addon without the strip's cell size, the game starts without its product code, the window's coordinates and Battle.net's second launch command are details (DEBUG); the models downloaded while installing are named for what they do. The companion's start line («запуск; настройки: …») is a detail too: the launcher says the companion started.
- The settings window asks whether to save when closed with changes (the cross and «Закрыть» dropped them silently, the Whisper check among them).
- Installing or updating the addon from the launcher mirrors it: files the new version no longer has are removed from the game's addon folder (they stayed before; harmless, as the game loads only what the .toc lists, but litter). The two files the companion writes there, VoiceList.lua and CompanionStatus.lua, are kept: an install overwrote them with the shipped empty ones, so after /reload the voice list was empty and the addon said the companion was not running.
- A companion started after the player entered the world says that the hidden chat needs a /reload - in the log and as a tray notice. Asked before its first beat (bv/reloadhint.py): «Прятать окно чата» on and the addon not switched off in its saved settings, no companion running a moment ago (a restart by the launcher: the addon saw that one), and the strip already on screen.
- The addon's settings have «Отладка (/bv debug)» under «Дополнительно», with a tooltip on what it writes and why to keep it off otherwise.
- «полоска видна, но не читается» is cleared when the strip reads again («полоска снова читается») or goes away: a second cover in the same session was not logged, and the launcher could keep showing «полоску что-то перекрывает» after the strip was gone for another reason.
- The launcher closing with the game no longer logs an error: the window was drawn once more after it was destroyed.
- Dictionary: «95%» is read «95 процентов» (1 процент, 2 процента), «кача» as к+ача, «ЛИ» (in capitals only: «ли» is a particle) as Лабиринты Иглошкурых, «пздц» as пиздец.
- A companion that stops (closed, crashed, ended by the launcher) marks its status file so: an addon loading after that says the companion is not running instead of «озвучка чата работает» from a beat of its last seconds. The transparent chat fades only while the companion was running at login or the last `/reload` — hidden lines nobody reads would be lost; a companion started later makes it transparent at the next `/reload`.
- A «Помощь» tab in the settings: where to write about bugs, ideas and words read wrong — Discord, Telegram and the GitHub issues, each with its icon, its address in a box (a click selects it, Ctrl+C copies) and «Копировать» and «Открыть». The game gives an addon neither the browser nor the clipboard, so the companion does both (bridge kinds `open` and `copy`, only for the addresses it knows). The welcome on the first run and the line after an update point to it.
- The race voices run through ONNX Runtime instead of torch: F5 exported to ONNX (DakeQQ/F5-TTS-ONNX, 10 steps) on DirectML — any DirectX 12 card, not only NVIDIA, though on DirectML the game stutters while a line is made (CUDA on NVIDIA, above) — and Whisper large-v3-turbo in ONNX for building the voice bank. The Python environment is 2.8 GB with CUDA (NVIDIA) or 0.6 GB with DirectML instead of 6.4 GB; a line takes about 1.1 s on an RTX 5070 Ti, as with torch. The models go into `models\f5-onnx` (`f5_onnx_dir`); `requirements-f5.txt` and `nfe_step` are gone, the library versions are pinned. RUAccent keeps its dictionary and models in the model cache (`hf_home`, folder `ruaccent`) instead of its package folder, so a new Python environment needs no download. The voice-type tooltip in the addon says «DirectX 12» instead of «NVIDIA».
- The strip («мост») is at the bottom edge of the screen by default (it was the top): «Внизу (обычно)» in «Мост к компаньону…». An addon with saved settings keeps its place.
- The launcher reads the companion's stderr apart from its log lines: a library writing below Python (a progress bar without its line end) glued itself to the next log line, which the main window then did not show — the first «собираю голоса рас из игры» among them. Such output is a `DEBUG [stderr]` line of its own, its last state, without colour codes.
- Building the voice bank (once, and after each game update) shows its progress: «собираю голоса рас: N из M» every 10 s, then «голоса рас собраны: N из M за X мин»; the launcher's main window keeps them in one line that moves on.
- The links to more Windows voices (RHVoice, Silero) on «Голоса» are rows of the same kind: the address to see and copy, «Копировать» and «Открыть».

## 0.3.0

- Retail WoW: the companion works with one chosen game — `WowChatVoice-Retail.cmd` (or `"game": "retail"`) starts it for retail: retail's folder, Battle.net's «WoW», a voice bank of its own (`voices-retail`). Voice files retail has not downloaded yet are taken from an installed WoW Forever: the same content keys, the same files. The addon's TOC lists both games' interface versions.
- Retail's races speak with their own voices from the game's Russian voice-over (the character's voice, three variants per sex): blood elves, draenei, goblins, worgen (and in human form), pandaren, dracthyr (and in dragon form), the allied races, earthen and haranir. A race whose recordings the client lacks speaks as its kin. Forever's bank keeps only Forever's races. A bank made while voice files were on no disk yet (retail is playable before Battle.net has downloaded all of it) is made again once the game's storage has grown by 100 MB; a complete bank never is.
- Retail closes chat to addons in dungeons, raids, boss fights, Mythic+ and PvP (text, sender and GUID come as secret values): such lines are not read and no error is raised; the addon says so once, and the hidden chat window shows them.
- The chat waits for Wayfarer (WayfarerRU) as for CatQuest: its quests, NPC lines, place lore and radio stories pause the chat, a paused Wayfarer does not. One setting for both: «Ждать озвучку квестов (CatQuest, Wayfarer)».
- The chat windows can stay out of sight («Прятать окно чата, пока на нём нет мыши», off by default): the chat is read aloud anyway, so the windows — text, background, tabs, edit box — are transparent until the mouse is over them or you type. A line the program does not read aloud (a system message, loot, a channel switched off, your own line, an addon's message) shows its window for 10 seconds; only lines in the tab on screen do (crafting nearby in a background combat log tab no longer flashes the chat). The mouse over the chat counts only when no other window lies over it there. A whisper or a guild line can show the window though it is read aloud, if asked («Показывать при шёпоте», «Показывать при строке гильдии», off by default).
- The settings window is in the game's own tabs now — «Общее», «Каналы и чтение», «Голоса», «Словарь» — instead of one long window and three more behind buttons. Each tab starts with a line on what is on it, and the window is as high as the tab needs. Speed and volume are on the first tab; the bridge settings are its foldable section; the Windows voices list and the dictionary are tabs of their own. The «Общие каналы» box holds its channels under it, as «Озвучивать имена» does. «Склонять замены после предлогов» and «Только то, что видно в окнах чата» are always on and no longer settings. Channel labels carry this client's own chat commands («Группа (/гр)»), and the settings say plainly whether the companion was running at login.
- Everything on «Каналы и чтение» is on by default (names, surnames, the verb, officers, emotes, own lines, numbered channels); saved settings stay as they are. In retail the tab has no «и фамилии» (retail names have no spaces) and no waiting for CatQuest and Wayfarer (Forever's addons).
- Under «Общие каналы» each numbered channel has its own box: General, Trade, Looking for group, Defense and the others — to read General and not Trade, say. All are on by default, so nothing changes until you switch one off.
- Speed and volume: the sliders' 100 % is now the default sound (it used to be 125 % speed and 120 % volume, which sounded better); the speed goes 40–160 % and the volume 0–200 %, so both marks stand in the middle at 100. Saved settings are converted once, so everything sounds as before.
- The settings say plainly that Windows voices sound mechanical and need installing for variety (Windows has only Irina), and are kept just in case: when race voices lag or do not run on the computer. Buttons «Скачать дополнительные голоса можно, например, здесь: RHVoice, Silero» there: the companion opens the voices' download page in the browser (bridge kind `open`, only pages of its own list).
- At login the chat says whether the reading works: «озвучка чата работает», or that the companion app is not running and the chat is read as soon as it is started. The companion notes the time in a file in the addon's folder every 15 seconds, and the game reads it at login and /reload (not during play); the settings show it too.
- A welcome on the first run: what the addon is, that the companion app does the reading, where the settings are. After an update, one line on what is new.
- The program learns where the strip is from the addon, which tells it before moving the strip, on the strip where it still is; no chat line is lost while it moves. If the program misses that, or is started while the game runs, it reads the place from the addon's saved settings, and failing that finds the strip anywhere in the game window within seconds.
- `/wcv last` no longer loses lines: a replay of more than 8 lines went past the companion's queue, and the extra ones were dropped (on a 14-line replay, 6 were); over 20 lines, the strip's queue dropped the first ones too. Replayed lines are now never dropped and do not count toward the queue's 8 live lines, and a line already made into sound waits for its turn instead of being thrown away. It remembers the last 50 lines across /reload and a game restart: they are kept in the addon's saved settings.
- Lines other players' addons write into the chat for them — Questie's party progress («{звезда} Questie: … 1/1»), DBM, BigWigs, Details! and others — are no longer read («Не читать сообщения аддонов», on by default): with Questie on two players in a group each progress line was read twice.
- A line that is nothing but questions is announced «Громмаш спрашивает: …» instead of «пишет» (the voices raise their tone at a question mark unevenly, the verb tells it by ear); yells and whispers keep their verbs.
- «ё» where the chat typed «е» and only «ё» can be meant («ждем» → «ждём», «еще» → «ещё», «утес» → «утёс»): the safe dictionary of eyo-kernel (MIT, about 107 thousand word forms); «все»/«всё» and the like stay as typed. `restore_yo` in config.json turns it off. RUAccent never put «ё» itself.
- The dictionary reads «тг» as «телеграм», «ага» with the stress on the last «а», «доведёте» (and «доведёт», «доведёшь», «доведём») and «Серёжа» in every case with «ё», «чиловая» as «чил+овая» in every form, «пиши» as «пиш+и», «губа» as «губ+а», «тикет» as «т+икет» in every form, «хелло» as «хелл+оу», «менеджмент» and «манаменеджмент» with the stress on «м+е» in every form, «др» as «дэ-+эр», «нюдес» (and «нюдсы») as «н+юдес», «чето» as «чёто», and «берет», «берете», «ружье» as «берёт», «берёте», «ружьё» (the «ё» dictionary leaves these: «берет» is a beret too, «ружье» a case of «ружьё»).
- «РЛ» is read as «руины Лордерона» (declined after a preposition: «у руин Лордерона»), and as «рейд-лидер» where the words around it say so («нужен РЛ», «РЛ сказал», «пишите РЛу», «с РЛом»). Declension: a hyphenated word declines as one («с рейд-лидером»), and «руины» as a thing («в руины», not «в руин»).
- «1 место» is read as a count, «одно место» (it was «первое»): in chat it is mostly «1 место в группу»; «15 место» and «на 2 месте» stay ordinal.
- The race voices option no longer says they come from CatQuest: since 0.2.0 they come from the game's own Russian voice-over.
- `/wcv reset` is gone: handing the race voices out again is the «Перераздать голоса» button, which asks first; a command for a thing done once in a blue moon is one more to remember.
- The companion stops at once, saying where it looked and what to do, when the addon is not installed — instead of launching the game and reading nothing.
- Skyborne (небеснорождённые), Forever's own race, speak with their own voices from the game's Russian voice-over — the character's voice, three variants per sex — instead of human ones. The voice bank is rebuilt once, a few minutes before the next game start.
- The companion keeps every model in one Hugging Face cache (`hf_home`, by default the `hf` folder next to it): Whisper, used to build the voice bank, lay in the system's cache apart from F5 and Vocos.
- Warnings and errors the libraries write to stderr (torch, transformers) go into the companion's log file too, marked `[stderr]`; their routine notices at start and while the voice bank is built (the deprecated `torch_dtype`, the tokenizer's clean-up, "use a dataset", torch's "Redirects are currently not supported") are left out.

## 0.2.1

- The dictionary reads «че» as «чё», «серега» as «серёга», «пикабу» as «пикаб+у», PvE as «пэ-вэ-йе».
- Several lines in a row from one character in one channel are read as one speech: the name only before the first, when the next line comes while the previous one is still being read or within 5 seconds after it ends (someone else in between — the name again).
- The dictionary is applied by the program now: it reads the default dictionary straight from the addon's files and picks up a change within seconds, with no /reload; your edits from the dictionary window come to it as before. A character's name is no longer run through the dictionary (a character named «Лок» stays «Лок»).
- Chat lines dropped after waiting too long for CatQuest are noted in the program's log.
- A chat line dropped because the queue is full (more than 8 lines waiting in a busy chat) is noted in the program's log; before, it vanished without a trace.
- `/wcv debug`: the addon notes in the program's log each chat line it does not send, with the reason (chat type off, not shown in any chat window, hidden by another addon's chat filter, your own), and when CatQuest starts and stops speaking — the log has the time the game's chat lacks.
- The chat no longer waits for CatQuest when CatQuest reports a track still playing well past the track's own length: its «playing» gets stuck at times, and chat lines were held and then dropped while nothing was heard.
- A number is read as an ordinal where only an ordinal fits: «с 15 уровня» — «с пятнадцатого уровня», «на 2 этаже» — «на втором этаже», «15 уровень» — «пятнадцатый уровень». With words that number rather than count (level, floor, place, rank, phase, season, chapter, act, wave, slot, boss) also «с 21 уровня» — «с двадцать первого» and «хил 15 уровня» — «пятнадцатого». Counts stay counts: «200 опыта», «на 2 уровня выше», «5 раз». «Число» as a date is a word that numbers: «до 11 числа» — «до одиннадцатого ч+исла». After an ordinal, «числа» and «места» get the singular's stress: the stress model always took them for the plural («числ+а», «мест+а»).
- The dictionary reads «аук» in every case as «аукцион» («на ауке» — «на аукционе»), and the Ragefire Chasm typed in full as «Огненная пр+опасть», not with the verb's stress «пропа́сть», in the case its preposition asks for («в Огненная Пропасть» — «в Огненную пропасть»).
- The dictionary reads «танчить» as «т+анчить» in every form, and «МСК» as «эм-эс-к+а».
- When CatQuest starts speaking while a chat line is being read, the chat stops at once and waits; once CatQuest is silent, the line it cut is read again from its start, then the rest. A pause whose end never reaches the program ends by itself after 90 seconds.
- Item links coloured by quality name ("|cnIQ1:", as newer clients send them) no longer leave the colour code in the speech, and two links in a row are read as two names. A colon right before a Russian letter («1:Сильный», «внимание:Привет») no longer garbles the letter: the rule for the «:Р» smiley took the Russian «Р» apart into bytes and ate the first byte of the letter.
- Where the strip is can be set: «Мост…» in the settings (the strip is called the bridge there, with a tooltip on what it is; the program is the companion app there, «приложение-компаньон», or just «компаньон») — the top edge (as before), the bottom edge, or a place of your own (X, Y and width in screen pixels; the fields start from the top or bottom line's numbers). Another addon drawing in the same place — such as wow-ai, which draws its own strip in the top left corner — hid ours, and chat lines were lost while it was up. While the window is open, an orange frame shows where the strip will go; «Сохранить» moves it.
- The strip is drawn above the rest of the game's interface: it belonged to the game world's frame, and everything in the interface — the minimap at the top right, the action bars at the bottom — was drawn over it whatever its layer. It still stays up when the interface is hidden (Alt+Z).
- The strip is as thick as it needs to be for the longest line: a narrow place of your own gets more rows (220 pixels wide — 7 rows, 14 pixels), and the bridge window shows the thickness. On a 1280-pixel-wide screen it now has two rows: one held 469 bytes, and parts of your dictionary edits (480 bytes) came to the program cut.
- The dictionary reads «кв» as «квест», and a number before «шт» as so many pieces in the right form: «6шт» — «шесть штук», «1 шт.» — «одна штука».
- A quest's number that quest addons put after its name in chat («[[25] Свиток с рунами (3513)]») is no longer read out.

## 0.2.0

- Race voices now come from the game client itself: the Russian voice-over of the playable races — each race and sex has the player character's voice and three NPC voice types (orc guard, shady and standard; human official, standard and warrior; …), each also in a lower and a higher copy, 12 voices per race and sex. Real actors instead of synthesized CatQuest voices: the orc sounds low and rough and the speech comes out clearer. CatQuest is no longer needed.
- The client's files are only read, never changed, and the game is not touched: the voice bank is made on your machine before the game starts, the first time and after each game update (a few minutes: Whisper hears the lines for their text), and kept until the next update.
- Slow voices speak faster: the game's recordings differ up to fourfold in tempo (a hurried error message of a character, a solemn NPC greeting), and a voice slower than the faster quarter of the voices is now drawn most of the way toward it (by at most 1.8 times; the Tauren elder went from 18.5 to 12.3 seconds on a test line); faster voices stay as they are. Each character also speaks at a tempo of their own (±8 %, from the name), so two characters given the same voice still sound like two people.
- Endings no longer get cut off: when a line's speech runs to the very end of the length given to it (one line in ten), it is made again with a quarter more length.
- The race voices load while the game starts instead of waiting for its first chat line (unless the addon was last set to Windows voices).
- Very high and very low voices no longer rasp in questions: the pitch analysis behind the question intonation had a fixed 60–500 Hz range, and gnome women speak at 450–500 Hz, the orc character at 55–70 Hz; outside the range it lost the voice's periods. It now follows the voice.
- Numbers get their stress like other words ("шестн+адцать", not "ш+естнадцать"): they are turned into words before the stress marks are put, not after.
- A line with a word the stress model splits its own way ("RU/UA", "<MIR>") no longer loses the stress marks of all its words ("игр+оков" for "игрок+ов"): only that word goes without.
- The dictionary reads Discord as «диск+орд», the Crossroads as «перекр+ёсток» and greaves as «п+оножи» in every case, and «ПС» as «Пещеры стенаний».
- A dictionary stem (an entry with `*`) keeps the case typed in chat: «на перекрёстке» was turned into «на перекрёсток», as the declension after a preposition is meant for abbreviations («в ОП») that have no ending of their own.
- The chat no longer talks over CatQuest: while CatQuest reads a quest, chat lines wait and are read once it is done (lines that waited over 40 seconds are skipped); a setting, on by default. The quest is not paused for the chat instead: the game cannot resume a sound in the middle, so the quest would start over after every chat line.
- Quest and item links read as their names: no brackets, no quest level tag ("[24]"), and the word before a link no longer runs into it.
- Words in capitals («РАЗЫСКИВАЕТСЯ», «ВСЁ», «СТОЙ») are read as words, not as abbreviations with the stress in the wrong place; an abbreviation the dictionary does not know is read letter by letter when it cannot be said as syllables, as in Russian speech: «ППС» — «пэ-пэ-эс», «ЦРУ», «США», and a syllable it begins with is said as one: «ГИБДД» — «ги-бэ-дэ-дэ»; «ОМОН» or «ВУЗ» are read as words.
- Swear words hidden from the chat filter are read as the words they are: a bracket pair for "х" ("на)(уя"; it used to become a full stop), Latin look-alike letters ("xyйня"), a digit inside a word ("п0шел") and asterisks for letters ("бл*ть").
- `assignments.json` (which voice each character has) no longer grows without end on a busy server: characters not heard for 60 days are forgotten (one who comes back gets a voice again, the same one when there are voices to go round), and the file is written every 30 seconds and on exit instead of on every chat line.
- Races without voices of their own in the client speak as their kin: goblins and vulpera as gnomes, blood elves as night elves, and so on. If you pinned a race voice to a player in `players`, the voice names changed (`orc-male/standard` and the like).
