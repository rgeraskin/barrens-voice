# 0003. Установщик для одного пользователя: Inno Setup + uv, всё в одной папке

Статус: принято (17.11.2026, 0.4.0). Заменяет `BarrensVoice.cmd` для игроков (он остался для запуска из исходников).

## Контекст

Игроку нужно поставить программу на Python с библиотеками на 0,6–2,8 ГБ (сборка зависит от видеокарты) и модели на 3 ГБ, не разбираясь в Python, и потом обновлять её без участия.

## Решение

Маленький установщик Inno Setup (около 13 МБ): в нём uv, `install.py` и архив выпуска. Python, библиотеки (из `uv.lock` выпуска) и модели скачиваются при установке. Установка — для текущего пользователя, без прав администратора, в одну папку (по умолчанию `%LOCALAPPDATA%\BarrensVoice`): код версий в `app\<версия>`, `app\current` — junction на текущую, `data` и `cache` рядом. Запускает всё `Barrens Voice.exe` в корне. `RedirectionGuard=no`: защита Inno Setup наследуется всем, что он запускает, и ломала uv на его же junction (ошибка 448); защита нужна установщикам с правами администратора, а этот ставит в папку того же пользователя.

## Альтернативы

- **Один большой exe (PyInstaller, Nuitka, встроенный Python).** 3 ГБ на каждое обновление, две сборки под видеокарты, сложная замена работающего файла.
- **Установка для всех пользователей (Program Files).** Нужны права администратора и UAC или служба для обновлений. Отложено («Когда-нибудь» в update-strategy, там же — почему нынешний установщик, возможно, почти подходит).
- **Python из системы, pip.** У игрока нет Python, и ставить его в систему — не наше дело.
- **conda.** Тяжелее и медленнее uv, а uv и так сам ставит Python и собирает окружение по lock-файлу.

## Последствия

- Обновление ставит версию рядом и переключает junction: откат — переключить обратно. Библиотеки берутся из кэша uv жёсткими ссылками — поэтому всё на одном диске.
- Неподписанный установщик вызывает SmartScreen, пока его не подпишем (update-strategy, «Подпись установщика»).
- Ярлыки, автозапуск и запись в «Приложениях» — только у того, кто ставил.
