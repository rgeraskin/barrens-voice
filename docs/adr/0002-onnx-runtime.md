# 0002. Голоса рас на ONNX Runtime: CUDA на NVIDIA, DirectML на остальных

Статус: принято (16.11.2026, 0.4.0). Заменяет работу через torch (до 0.3.0).

## Контекст

До 0.3.0 F5-TTS и Whisper работали через torch на CUDA: только NVIDIA, окружение Python 6,4 ГБ. Хотелось голоса рас на любой видеокарте и окружение меньше.

## Решение

F5, экспортированный в ONNX (DakeQQ/F5-TTS-ONNX, 10 шагов), и Whisper в ONNX — на ONNX Runtime. На NVIDIA — сборка с CUDA (`onnxruntime-gpu`), на остальных видеокартах с DirectX 12 — DirectML. Установщик выбирает сборку по видеокарте. Сессию, которую ONNX Runtime молча перевёл на процессор, программа не принимает и читает голосами Windows.

## Альтернативы

- **Остаться на torch.** Только NVIDIA и 6,4 ГБ.
- **DirectML и на NVIDIA.** Замер «игры» на видеокарте: DirectML занимает её на весь шаг синтеза (~100 мс), и кадры игры ждут — около 130 подвисаний за 18 с. С CUDA подвисаний нет (DEVELOPMENT, «F5-TTS и банк голосов»).
- **Процессор.** 38–103 с на фразу — голоса рас без видеокарты невозможны (DEVELOPMENT, «Исследования»).
- **Ускорители производителей для AMD и Intel.** Сборки ONNX Runtime с ROCm и MIGraphX — только для Linux. На Windows к ним ведёт Windows ML (Windows 11 24H2+) или отдельные пакеты провайдеров, часть из них пока заглушки. Без карт AMD и Intel проверить нельзя — отложено до отзывов игроков (DEVELOPMENT, «Исследования»).

## Последствия

- Окружение 2,8 ГБ с CUDA и 0,6 ГБ с DirectML, строка около 1,1 с на RTX 5070 Ti — как с torch.
- На видеокартах не NVIDIA игра может подтормаживать, пока готовится фраза ([docs/gpu.md](../gpu.md)). Выход — голоса рас без видеокарты (Piper, Roadmap).
- Две сборки ONNX Runtime исключают друг друга в одном окружении (`[tool.uv] conflicts`).
