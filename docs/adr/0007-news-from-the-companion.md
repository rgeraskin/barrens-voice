# 0007. «Что нового»: один файл news.toml по версии программы, в игру его приносит компаньон

Статус: принято (18.11.2026, 0.4.0).

## Контекст

Игрокам после обновления нужно короткое «что нового» по-русски: в игре (окно или строка в чате) и в описании выпуска на GitHub. CHANGELOG.md — подробный английский список для разработчиков, игроку он не годится. Сначала записи лежали в аддоне (`News.lua`) и были привязаны к версии аддона. Но выпуск, в котором изменилась только программа, версию аддона не поднимает ([0005](0005-separate-versions.md)): о нём игрок не узнал бы, если не поднимать аддон нарочно, а описание выпуска на GitHub собиралось из CHANGELOG — второй текст о том же.

## Решение

Один источник — `news.toml` в корне репозитория: по записи на выпуск, по версии программы (`pyproject.toml`), с датой при выпуске, `big` или `small`, заголовком, строкой для чата и пунктами. `tools/release.py` делает из записи выпуска его описание на GitHub (плюс ссылка на CHANGELOG.md на теге) и не соберёт выпуск без записи его версии с датой. Файл едет в архиве выпуска; компаньон при старте пишет записи, которые показывает его версия, вместе с самой версией в `NewsData.lua` в папке аддона — так же, как `VoiceList.lua` и `DictionaryOnline.lua`. Аддон сравнивает и помнит прочитанное по этой версии программы.

## Альтернативы

- **Записи в аддоне, по версии аддона.** Выпуск только программы молчит, или аддон поднимают ради одной записи — и лаунчер переставляет его во всех играх без изменений в коде.
- **Записи в аддоне, по версии программы.** Аддон не знает версию программы, а поднимать его ради записи — то же, что выше.
- **Описание выпуска из CHANGELOG, записи отдельно.** Два текста о том же, и на странице выпуска — английский для разработчиков.
- **Формат Lua вместо TOML.** Python читает TOML сам (`tomllib`), а таблицу Lua `release.py` разбирал регулярками по первой строке записи. Lua для аддона компаньон пишет сам, с экранированием.

## Последствия

- До первого запуска компаньона с новой версией в игре нет записей: окно говорит, откуда они берутся. Новые записи видны со следующего входа или `/reload`.
- Записи не поднимают версию аддона; аддон без программы (в будущем — с CurseForge) записей не покажет.
- `seenVersion` в сохранённых настройках раньше хранил версию аддона, теперь — программы; для перехода это не важно, номера выпусков до 0.4.0 у обоих совпадают.
- В текстах запрещены «→», «–» и «|»: проверяют тесты и `release.py`, а компаньон запись с ними пропускает.
