# Ручные проверки

Что стоит проверить руками в игре: тестами не покрывается или ещё не проверялось на настоящем клиенте. Проверили — отметьте `[x]`, дату и что вышло; нашлась ошибка — опишите её здесь же.

## Полоска видна, но кадры не читаются

Компаньон отличает «полоски нет» от «полоска есть, но кадр не сходится» (её что-то перекрывает). Распознавание покрыто тестами (`test_protocol.py`), сообщения и состояние в лаунчере — нет; исправление повторного сообщения — коммит `acc2a58`.

- [ ] В аддоне: «Общее» → «Дополнительно» → «Мост к компаньону…» → «своё место»; полоска вверху справа (Y = 0), X — так, чтобы её конец заходил под миникарту. «Сохранить».
- [ ] Через секунду в журнале — «полоска видна, но кадры не читаются…», в лаунчере — красное «Мост: полоску что-то перекрывает».
- [ ] Вернуть полоску наверх («вверху»): в журнале — «полоска снова читается», в лаунчере — зелёное «Мост: связь с аддоном есть».
- [ ] Повторить перекрытие: сообщение в журнале появляется снова (раньше второй раз не писалось).
- [ ] Перекрыть и свернуть игру: лаунчер показывает «окно игры свёрнуто или не найдено», а не «перекрывает».

## Гамма

README («Ограничения») утверждает: при сильно затемнённой гамме компаньон может перестать различать ячейки полоски. Не проверялось.

- [ ] Настройки графики игры → гамма на минимум: читается ли полоска (строки чата озвучиваются)?
- [ ] Гамма на максимум — то же.
- [ ] Если не читается — с какого значения; в журнале при этом «полоска видна, но кадры не читаются» или «полоска аддона пропала». Поправить README по результату.

## Компаньон запущен посреди игры: напоминание про /reload

Аддон узнаёт о компаньоне только при входе и `/reload`, поэтому запущенный позже компаньон напоминает, что прозрачному чату нужен `/reload` (если полоска видна сразу после запуска и в сохранённых настройках аддона «Прятать окно чата» включено).

- [ ] В аддоне включить «Прятать окно чата», выйти из игры и снова войти без компаньона: аддон пишет «Прозрачный чат пока выключен…».
- [ ] Запустить Barrens Voice, пока персонаж в мире: в журнале — «если окно чата не прячется — сделайте в игре /reload…», в трее — уведомление.
- [ ] `/reload`: окно чата прячется, при входе аддон пишет «озвучка чата работает».
- [ ] С выключенным «Прятать окно чата» напоминания нет.
- [ ] Аддон выключен (`/bv off`), «Прятать окно чата» включено: напоминания нет.
- [ ] Посреди игры сохранить настройки в лаунчере (компаньон перезапустится): напоминания нет, окно чата прячется как прятался.
- [ ] Barrens Voice запущен до входа в мир (на экране выбора персонажа): напоминания нет, чат прячется сразу.

## Галочка «Отладка» в настройках аддона

- [ ] «Общее» → «Дополнительно»: галочка «Отладка (/bv debug)» над «Мост к компаньону…», подсказка при наведении, тексты не наезжают.
- [ ] Включить галочкой: в журнале компаньона появляются строки «диагностика аддона»; `/bv debug` выключает, галочка при следующем открытии настроек снята.
- [ ] Раскрыть «Мост к компаньону…»: галочку не закрывает.

## Установщик

Проверено на тестовой машине без самого установщика (17.11.2026): `install.py` ставит выпуск (151 с с пустым кэшем, 5 с с кэшем), окружение видит CUDA, код находит `data\` и `cache\`; обновление 0.4.0 → 0.4.1 из подписанного выпуска (`BV_UPDATE_BASE=file:///…`) и откат после двух падений на старте — скриптом. Не проверено:

- [x] Сборка в CI (17.11.2026): `BarrensVoice-Setup-0.4.0.exe`, 12,9 МБ.
- [x] beta.1: uv из установщика упал с ошибкой 448 («untrusted mount point»): Inno Setup включает RedirectionGuard, и запущенное им наследует защиту — uv не проходит через свою же junction. Флаг `runasoriginaluser` не помог (beta.2: установщик без прав администратора всё равно передаёт защиту); выключено `RedirectionGuard=no` (beta.3) — защита нужна установщикам с правами администратора, а этот ставит в папку того же пользователя.
- [ ] Установка на чистую учётную запись Windows: выбор папки, ход загрузки в окне консоли, модели, значки в «Пуске» и на рабочем столе, запуск лаунчера в конце.
- [ ] Значок лаунчера и иконка в «Приложениях» Windows.
- [ ] Удаление: процессы этой установки останавливаются, значение автозапуска удаляется, вопрос про данные и модели (и «Да», и «Нет»).
- [ ] Установка поверх (та же версия, более новая).
- [ ] С видеокартой не NVIDIA — ставится DirectML (можно `--runtime directml` в `install.py`).

## Обновление из лаунчера

- [ ] Выпуск на GitHub (или `BV_UPDATE_BASE`): лаунчер при запуске пишет «вышла версия…», скачивает и готовит её, полоса внизу — «скачивается… / готовится… / включится после игры».
- [ ] Игра запущена — переключение ждёт; игра закрыта — «перехожу на версию…», лаунчер перезапускается уже новой версией (в трей, если был в трее).
- [ ] «Обновлять автоматически» выключено: полоса «Вышла версия…» с кнопкой «Обновить», та готовит версию.
- [ ] «Получать тестовые версии»: pre-release находится; снятая галочка — остаёмся на тестовой до стабильной новее.
- [ ] Выпуск с неверной подписью или подменённым архивом — не ставится, в журнале — почему.
- [ ] Новая версия, у которой компаньон падает на старте: после второго падения — откат и уведомление.
