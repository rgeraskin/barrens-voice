# Ручные проверки

Что стоит проверить руками в игре: тестами не покрывается или ещё не проверялось на настоящем клиенте. Проверили — перенесите пункт в [verified.md](verified.md) с датой, клиентом игры и тем, что вышло; нашлась ошибка — опишите её здесь, пока не исправлена.

## Полоска видна, но не читается

Компаньон отличает «полоски нет» от «полоска есть, но кадр не сходится» (её что-то перекрывает). Распознавание покрыто тестами (`test_protocol.py`), сообщения и состояние в лаунчере — нет; исправление повторного сообщения — коммит `c4dee99`.

- [ ] В аддоне: «Общее» → «Дополнительно» → «Мост к компаньону…» → «своё место»; полоска вверху справа (Y = 0), X — так, чтобы её конец заходил под миникарту. «Сохранить».
- [ ] Через секунду в журнале — «полоска видна, но не читается…», в лаунчере — красное «Мост: полоску что-то перекрывает».
- [ ] Вернуть полоску на место («внизу»): в журнале — «полоска снова читается», в лаунчере — зелёное «Мост: связь с аддоном есть».
- [ ] Повторить перекрытие: сообщение в журнале появляется снова (раньше второй раз не писалось).
- [ ] Перекрыть и свернуть игру: лаунчер показывает «окно игры свёрнуто или не найдено», а не «перекрывает».

## Гамма

README («Ограничения») утверждает: при сильно затемнённой гамме компаньон может перестать различать ячейки полоски. Не проверялось.

- [ ] Настройки графики игры → гамма на минимум: читается ли полоска (строки чата озвучиваются)?
- [ ] Гамма на максимум — то же.
- [ ] Если не читается — с какого значения; в журнале при этом «полоска видна, но не читается» или «полоска аддона пропала». Поправить README по результату.

## Компаньон запущен посреди игры: напоминание про /reload

Аддон узнаёт о компаньоне только при входе и `/reload`, поэтому запущенный позже компаньон напоминает, что прозрачному чату нужен `/reload` (если полоска видна сразу после запуска и в сохранённых настройках аддона «Прятать окно чата» включено).

- [ ] В аддоне включить «Прятать окно чата», выйти из игры и снова войти без компаньона: аддон пишет «Прозрачный чат пока выключен…».
- [ ] Запустить Barrens Voice, пока персонаж в мире: в журнале — «если окно чата не прячется — /reload в игре», в трее — уведомление «…сделайте в игре /reload…».
- [ ] `/reload`: окно чата прячется, при входе аддон пишет «озвучка чата работает».
- [ ] С выключенным «Прятать окно чата» напоминания нет.
- [ ] Аддон выключен (`/bv off`), «Прятать окно чата» включено: напоминания нет.
- [ ] Посреди игры сохранить настройки в лаунчере (компаньон перезапустится): напоминания нет, окно чата прячется как прятался.
- [ ] Barrens Voice запущен до входа в мир (на экране выбора персонажа): напоминания нет, чат прячется сразу.

## Галочка «Отладка» в настройках аддона

- [ ] «Общее» → «Дополнительно»: галочка «Отладка (/bv debug)» над «Мост к компаньону…», подсказка при наведении, тексты не наезжают.
- [ ] Включить галочкой: в журнале компаньона появляются строки «диагностика аддона»; `/bv debug` выключает, галочка при следующем открытии настроек снята.
- [ ] Раскрыть «Мост к компаньону…»: галочку не закрывает.

## Установщик

Что уже проверено — в [verified.md](verified.md).

- [ ] `Barrens Voice.exe` запускается двойным щелчком; «Запускать при входе в Windows» → после входа лаунчер в трее (значок и ярлыки проверены, см. verified.md).
- [ ] Установка на чистую учётную запись Windows: выбор папки, ход загрузки в окне консоли, модели, значки в «Пуске» и на рабочем столе, запуск лаунчера в конце.
- [ ] После обновления «Приложения» Windows показывают новую версию (исправлено, версию пишет лаунчер при запуске).
- [ ] Удаление: процессы этой установки останавливаются, значение автозапуска удаляется, вопрос про данные и модели (и «Да», и «Нет»).
- [ ] Установка поверх (та же версия, более новая).
- [ ] Видеокарта не NVIDIA: голоса рас работают на DirectML (сборка ставится — verified.md), насколько подтормаживает игра.

## Обновление из лаунчера

- [ ] Плашка на экране: «обновление скачивается… / готовится… / ждёт закрытия игры» с кнопкой «Установить сейчас», справа «Что нового» (сама цепочка обновления проверена — verified.md). Аддон старше нового обновляется в закрытых играх сам («аддон обновлён до …»), если включено «Обновлять автоматически».
- [ ] WoW Retail: аддон, заменённый при запущенной игре, подхватывается `/reload` (как на Forever, см. verified.md). По патчноутам Blizzard так с 9.0.1; не проверяли. Та же проба: временный аддон, изменённый и новый .lua, новая и изменённая картинка.
- [ ] Во время игры «Установить сейчас» → «Да»: компаньон останавливается, лаунчер перезапускается с новой версией (в заголовке — новая версия), озвучка снова работает примерно через полминуты.
- [ ] Лаунчер в трее при переключении версии перезапускается снова в трей.
- [ ] «Обновлять автоматически» выключено: полоса «Вышла версия…» с кнопкой «Обновить», та готовит версию.
- [ ] Снятая «Получать тестовые версии» — остаёмся на тестовой до стабильной новее (находится ли pre-release — verified.md).
- [ ] Новая версия, у которой компаньон падает на старте: после второго падения — уведомление в трее (сам откат проверен — verified.md).

## Полоска внизу по умолчанию

С 0.4.0 полоска по умолчанию у нижнего края. Сохранённое место старых установок не меняется. Компаньон в первый раз смотрит вверху и находит полоску поиском по окну.

- [ ] Удалить сохранённые настройки аддона (`WTF\Account\…\SavedVariables\BarrensVoice.lua`), войти в игру: полоска внизу, в «Мост к компаньону…» выбрано «Внизу (обычно)».
- [ ] Компаньон находит её за несколько секунд («полоска найдена в другом месте» в полном журнале), в лаунчере — «Мост: связь с аддоном есть».
- [ ] После `/reload` и перезапуска компаньона связь есть сразу (место берётся из сохранённых настроек).

## Прогресс сборки банка голосов

Банк собирается в первый раз и после каждого обновления игры. Проверить можно, удалив папку `data\voices` (игра закрыта, компаньон остановлен).

- [ ] В главном окне лаунчера одна строка: «собираю голоса рас из игры…» → «собираю голоса рас: N из M» (обновляется раз в 10 с) → «голоса рас собраны: N из M за X мин».
- [ ] В полном журнале («Журнал») — все промежуточные строки; строки библиотек — отдельными `DEBUG [stderr]`, ни одна INFO-строка не пропала.

## Словарь онлайн

- [ ] Без сети: запуск берёт словарь из `data`.

## Фильтры чата, /bv off, обновления и установщик (0.4.0)

В игре:

- [ ] Строку, которую прячет антиспам-аддон (фильтр чата другого аддона), Barrens Voice не читает (Forever вызывает фильтры через `ChatFrameUtil.ProcessMessageEventFilters`).
- [ ] Прозрачный чат по-прежнему показывает непрочитанные строки (наш фильтр теперь добавляется через `ChatFrameUtil.AddMessageEventFilter`).
- [ ] `/bv off`, подождать пару минут, нажать «Проверка» и «Открыть» у ссылки, `/bv on`: ничего старого не звучит и не открывается.
- [ ] «кто в рейд?» и «Цена?» звучат как вопрос, со словом «спрашивает».

На Windows (проверено только на заглушках):

- [ ] Обновление: переключение версии (`current.new` → `current`), проверка новой версии её Python, удаление старых версий и архивов после удачного запуска.
- [ ] Перезапуск после обновления с `--updated`: при запущенной игре озвучка включается, игра второй раз не запускается. С «Закрываться вместе с игрой» лаунчер закрывается без перезапуска.
- [ ] Версия, с которой откатились, не готовится снова сама, плашка о ней остаётся.
- [ ] Установщик: собирается (`{code:}` в `[UninstallRun]`), путь с пробелом и `&`, удаление при апострофе в пути, отказ запускаться поверх работающего Barrens Voice (`AppMutex`).
- [ ] Битый `config.json`: компаньон не запускается, в окне — где ошибка, файл не перезаписан, отката версии нет.
- [ ] Журнал лаунчера больше 1 МБ переименовывается и пишется дальше.
- [ ] Игра находится по `Wow.exe` в папке игры, программа вроде WowUp игрой не считается.
- [ ] Компаньон в консоли перезапускается сам (путь с пробелом).

- [ ] Кнопка «Проверка» в окне голосов; «Открыть» и «Копировать» у ссылок в помощи.

## Аддон при выключенной озвучке, длинная строка словаря, обновления и config.json (0.4.0)

Исправления покрыты тестами на заглушках; игру, Windows и настоящие процессы они не видят.

В игре (для аддона хватает `/reload`):

- [ ] В окне словаря набрать строку длиннее 480 байт (длинную регулярку), с паузами больше 2 с: в чате одно сообщение «строка словаря длиннее 480 байт…», а не по одному на паузу, и `|` в нём видны, как набраны.
- [ ] С этой строкой `/reload`, затем перезапустить компаньон: правило из неё не работает (его нет ни в кадрах, ни в сохранённых настройках).
- [ ] С CatQuest или Wayfarer: пока читается квест, написать в чат пару строк, `/bv off`, `/bv on`, дождаться конца квеста — эти строки не звучат.
- [ ] После `/bv off` каждое из этого пишет, что озвучка выключена: `/bv last`, `/bv stop`, «Открыть» и «Копировать» у ссылки (адрес при этом показан), «>» в окне голосов, «Озвучить» в окне словаря, переключатель «Голоса рас / Голоса Windows» (компаньон переключится при `/bv on`).
- [ ] `/bv reset-voices` при выключенном аддоне, `/reload`, `/bv on`: в журнале компаньона перераздача голосов один раз.

На Windows:

- [ ] Прослойка venv: в журнале лаунчера pid процесса компаньона (`Popen`) и pid в `data\tmp\state.json` — разные ли они. Ошибка, которую компаньон объяснил сам (нет аддона), у только что поставленной версии не считается падением в любом случае.
- [ ] Junction `app\current`: переключение версии, пока старая занята (открыт её файл), и удаление старых версий, пока одна из них используется, — ничего не ломается, лишнее уходит при следующем удачном запуске.
- [ ] Установщик собирается Inno Setup (`[UninstallRun]` с одиночными `}`), а настоящее удаление останавливает работающие лаунчер и компаньон этой установки.
- [ ] `installer/launcher.cs` собирается компилятором .NET Framework (`csc`) и, если `app\current` нет, запускает версию из `current.new`, а без неё — из `current.old`.
- [ ] Игра запущена от администратора или от другого пользователя (`OpenProcess` не открывает `Wow.exe`): «Играть» не запускает вторую игру, в журнале «игра уже запущена».
- [ ] `"f5_onnx_provider": "TensorrtExecutionProvider"` на машине, где TensorRT не поднимается: голоса рас не включаются («… не запустился на этой видеокарте»), чат читается голосами Windows.
- [ ] `config.json` занят другим процессом (открыт без общего доступа): компаньон с «Закрываться вместе с игрой» перечитывает его, когда файл освободится, а лаунчер при сохранении настроек говорит «config.json не открывается…» и файл не перезаписывает.
- [ ] Игра держит `VoiceList.lua` или `DictionaryOnline.lua` открытым, и запись не удаётся: в папке аддона не остаётся `*.lua.tmp`.
- [ ] Удалить папку `data\tmp` (там `line*.wav` проигрывателя), пока компаньон работает: следующие строки чата звучат, папка появляется снова.
- [ ] «Играть» с актуальным банком голосов: в журнале нет «игра запустится, когда соберутся голоса рас». После обновления игры (банк собирается заново) — есть.

## Обновление на Windows: удаление версий, прерванное переключение, config.json только для чтения (0.4.0)
