# Видеокарты

Голоса рас (нейросеть F5-TTS) готовят каждую фразу на видеокарте. На процессоре строка готовится десятки секунд, это непригодно.

- **NVIDIA** — через CUDA (ONNX Runtime с CUDA ставится сам, когда установщик находит драйвер NVIDIA). Проверено: игра при озвучке идёт плавно.
- **AMD и Intel** (любая видеокарта с DirectX 12) — через DirectML. Работает, но по замерам на NVIDIA игра подтормаживает, пока готовится фраза: DirectML отдаёт видеокарте весь шаг синтеза (~0,1 с) одним куском, и кадр игры ждёт его конца — примерно по рывку на шаг. Быстрая видеокарта делает рывки короче, но не убирает. На самих AMD и Intel это **не проверено** — там может оказаться и лучше.
- Если рывки мешают — выберите голоса Windows (`/bv`, вкладка «Голоса»): они не нагружают видеокарту.

**Ищем игроков с видеокартами AMD и Intel, готовых потестировать:** включите голоса рас и напишите (см. «Ошибки и идеи» в README), заметны ли рывки, с названием видеокарты. Если рывки подтвердятся и вы готовы проверять сборки — я добавлю поддержку ускорителей AMD и Intel для ONNX Runtime. А можно и сразу прислать pull request 🙂 Как это можно сделать — в DEVELOPMENT.md («Ускорители AMD и Intel вместо DirectML»).

В планах — голоса рас на процессоре (Piper, см. Roadmap в README): без видеокарты и без рывков на любой.
