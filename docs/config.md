# Настройки компаньона: config.json

Обычные настройки — в окне лаунчера и в аддоне (`/bv`); здесь — то, что есть только в `config.json`. Открыть его: «Настройки» → «Открыть config.json» в лаунчере. Компаньон читает файл при запуске: после правки перезапустите Barrens Voice (крестик, затем снова открыть). Ключа нет в файле — действует значение по умолчанию.

В папке `data` установки (запуск из исходников — рядом с компаньоном) появляются `config.json` (настройки), `logs/` (журналы), `voices/` (банк голосов; у ритейла — `voices-retail/`) и `assignments.json` (какой голос у какого персонажа; тех, кого не было слышно 60 дней, компаньон забывает). Чаще всего нужны:

- `players`: закрепить голос за игроком — `{"Ник": "orc-male/standard"}` для голосов рас (названия — в `voices/bank.json`) или `{"Ник": "Svetlana"}` для голосов Windows.
- `exclude`: голоса Windows, которые не раздавать (часть названия).
- `game_dirs`: папка каждой игры — `{"forever": "…\\_forever_", "retail": "…\\_retail_"}`; её задают поля «Папка WoW Forever» и «Папка WoW Retail» в настройках лаунчера, и лаунчер сам запоминает папку игры, которую увидел запущенной. Старый ключ `wow_dir` (одна папка) тоже читается.
- `hf_home`: кэш моделей Hugging Face (Whisper для сборки банка голосов, словарь F5). По умолчанию папка `hf` рядом с компаньоном; модели скачиваются туда один раз.
- `launch_wow`, `exit_with_wow`: запускать ли игру вместе с Barrens Voice (по умолчанию нет — игру запускает «Играть» или Battle.net) и закрываться ли вместе с ней (по умолчанию да).
- `question_intonation`: сила вопросительной интонации (0 — выключить).
- `restore_yo`: ставить «ё», где в чате написали «е» («ждем» → «ждём», «еще» → «ещё»; включено). Только в словах, где «е» быть не может: «все» и «всё», «берет» и «берёт» остаются как написаны.
- `voice_pace_blend`, `voice_pace_limit`, `character_tempo`: насколько ускорять медленные голоса (0 — как в записях игры, 1 — до темпа быстрой четверти голосов; по умолчанию 0,85, не больше чем в 1,8 раза) и разброс личного темпа персонажей (±8 %).
- `f5_onnx_dir`: папка с моделями F5 в ONNX, если они уже есть у вас (по умолчанию `models\f5-onnx` рядом с компаньоном, а нет их там — скачиваются с Hugging Face, `f5_onnx_repo`); `f5_onnx_provider`: через что их выполнять — по умолчанию сам выбирает: `CUDAExecutionProvider` (NVIDIA), иначе `DmlExecutionProvider` (DirectML); `CPUExecutionProvider` — процессор, но там строка готовится десятки секунд.
- `share_with_game`, `onnx_threads`: уступать игре (включено) — компаньон работает с приоритетом ниже обычного на процессоре и видеокарте, а нейросети берут не больше `onnx_threads` (2) ядер; без этого игра могла подтормаживать на каждой озвученной строке.
- `f5_end_check` (галочка «Проверять концовки фраз…» в настройках лаунчера): изредка голос расы не успевает договорить последний слог. `"silence"` (по умолчанию) — фраза, договорённая впритык (примерно каждая восьмая), синтезируется ещё раз, на секунду дольше; `"whisper"` — Whisper сначала слушает её конец и переделывает только при обрыве, но занимает около 1,5 ГБ видеопамяти.
- `dictionary_online`: брать свежий стандартный словарь с GitHub без обновления аддона (у установленного Barrens Voice включено; `false` — выключить и пользоваться только словарём из аддона).
- `log_details`, `log_keep_days`: подробность журнала и сколько дней его хранить (90; 0 — всегда).
