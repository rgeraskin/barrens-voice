## Словарь онлайн

- 17.11.2026: CI создал ветку `dictionary` (ревизия 1794928158). Код программы из выпуска beta 9 скачивает файл с `raw.githubusercontent.com`, принимает подпись, кладёт копию в `data` (она снова проходит проверку при запуске), пишет `DictionaryOnline.lua`, и LuaJIT его загружает. Ревизия совпала с `D.REVISION` словаря в выпуске — используется словарь аддона (тот же текст), как и задумано.
- 17.11.2026, установка игрока (beta 11, игра запущена): «импрувед» добавлен в master без беты; CI опубликовал ревизию 1794935862, и через час после запуска компаньон сам её скачал (21:13:13), записал «свежий словарь с GitHub — в окне словаря после /reload» и обновил `DictionaryOnline.lua` в папке аддона; после `/reload` слово видно и в окне словаря. В тот же вечер beta 9 сама обновилась до beta 11 и заменила аддон в игре на 0.4.0b1.
- Найдено и исправлено: на Windows-раннере файл подписывался с `\r\n`, а git в ветке хранил `\n` — подпись не сходилась. Теперь файл пишется байтами с `\n`, ветка хранит байты как есть. GitHub отдаёт файлы ветки через CDN с кэшем до 5 минут: новый словарь доходит не сразу.

## Установщик

- 17.11.2026, установка игрока: неподписанный установщик вызывает предупреждение SmartScreen — так и написано в README.
- 17.11.2026, тестовая машина: `install.py --runtime directml` ставит сборку DirectML за 26 с (Python, библиотеки), ONNX Runtime 1.24.4 видит `DmlExecutionProvider`. Синтез на видеокарте не NVIDIA не проверялся: такой нет.
- 17.11.2026, установка игрока: у `Barrens Voice.exe` значок программы; ярлыки в «Пуске» и на рабочем столе ведут на него; запись в «Приложениях» — с его значком и папкой установки. Автозапуск при входе пишет в реестр `"Barrens Voice.exe" --tray` (по коду и тестам `Starter`; на машине он выключен).

Проверено на тестовой машине без самого установщика (17.11.2026): `install.py` ставит выпуск (151 с с пустым кэшем, 5 с с кэшем), окружение видит CUDA, код находит `data\` и `cache\`; обновление 0.4.0 → 0.4.1 из подписанного выпуска (`BV_UPDATE_BASE=file:///…`) и откат после двух падений на старте — скриптом.

- Сборка в CI (17.11.2026): `BarrensVoice-Setup-0.4.0.exe`, 12,9 МБ.
- beta.1: uv из установщика упал с ошибкой 448 («untrusted mount point»): Inno Setup включает RedirectionGuard, и запущенное им наследует защиту — uv не проходит через свою же junction. Флаг `runasoriginaluser` не помог (beta.2: установщик без прав администратора всё равно передаёт защиту); выключено `RedirectionGuard=no` (beta.3) — защита нужна установщикам с правами администратора, а этот ставит в папку того же пользователя.
- beta.3 (17.11.2026, тестовая машина, установка на втором диске): установка прошла (Python, библиотеки с CUDA, модели), но лаунчер упал при первой отрисовке — снимок окна и его разбор в `redraw` разошлись на одно значение (добавлено `updating`); ярлык без значка — значок указывал в `app\current`, которого при создании ярлыков ещё нет. Исправлено в beta.4: тест `WindowCode` сверяет снимок с разбором, значок — отдельный файл `BarrensVoice.ico`.
