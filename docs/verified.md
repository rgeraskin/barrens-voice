## Программа на Windows (проверено без игрока)

- 19.11.2026, тестовая машина, отдельная установка беты 18 в папке с пробелом (поддельная папка игры, установку игрока не трогали):
  - Компаньон в консоли без моделей RUAccent в кэше (`.models_ready` на месте): «в кэше моделей не всё — перезапускаюсь с сетью», новый процесс сам докачивает модели («Голоса рас готовы.»), без «OfflineModeIsEnabled», метка записана заново.
